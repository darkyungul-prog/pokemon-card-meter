# 포켓몬카드 측정기 — STEP 1 카메라 테스트

이번 버전의 목적은 **가격 검색이나 카드 인식이 아닙니다.**

## 이번 단계에서 반드시 확인할 것
1. 앱 실행 시 Android 카메라 권한 요청
2. 권한 허용 후 앱 화면 안에서 후면 카메라 미리보기 표시
3. 포켓몬 카드 비율에 맞춘 노란색 네 모서리 가이드 표시
4. `카드 촬영` 버튼으로 앱 내부에서 사진 촬영
5. 촬영한 카드 사진을 즉시 앱 화면에 표시
6. `다시 촬영` 가능

이 단계가 실제 휴대폰에서 정상 동작하는 것을 확인한 뒤 STEP 2에서 촬영 이미지를 서버로 전송하고 OpenAI Vision으로 카드명, 세트코드, 카드번호, HP, 희귀도를 JSON으로 받아 자동 입력합니다.

## 빌드
GitHub Actions의 `Build Android APK`가 자동으로 Debug APK를 만들고 `camera-test` Release에 APK를 게시하도록 구성되어 있습니다.
